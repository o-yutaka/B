# 001 Decision Ontology

## Purpose

Define the conceptual objects used by BLACK decisions.

## Core Objects

| Object | Meaning |
| --- | --- |
| Decision | A selected course of action under evidence |
| Evidence | The recorded basis for accepting or rejecting a decision |
| Context | The operating conditions surrounding a decision |
| Consequence | The observed result after execution |
| Replay | Reconstruction of the decision path |

## Constraint

The ontology describes BLACK decisions; it does not replace BLACK itself.
