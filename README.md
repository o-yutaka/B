# BLACK ORIGIN

BLACK ORIGIN is a modular planetary intelligence operating system designed to run in a single-node environment.

## Run

```bash
python server.py
```

Open `http://localhost:8000` in a browser (mobile Safari compatible layout).

## Implemented architecture

- Core runtime kernel with continuous global intelligence loop.
- Planetary data discovery and indexing engines.
- Knowledge graph + causal graph inference pipeline.
- World model, simulation, prediction, research, and self-evolution engines.
- Agent system with collector/analysis/simulation/strategy/research agents.
- Mobile-first UI with chat interface, module workspace, and Three.js planetary graph.

## Memory files

Created automatically in `memory/`:

- `planetary_index.json`
- `knowledge_graph.json`
- `causal_graph.json`
- `world_model.json`
- `event_stream.json`
- `sensor_data.json`
- `research_memory.json`
