# BLACK v1.0 Roadmap

## Phase 0: Architecture Bootstrap

Create repository layout, lifecycle interfaces, specifications, and placeholder tests only.

## Phase 1: Runtime Registration

Wire modules into the existing RuntimeEngine lifecycle without changing RuntimeEngine or EventBus semantics.

## Phase 2: Evidence-Driven Decision Loop

Implement kernel, memory, governance, execution, feedback, and compression behavior behind the approved interfaces.

## Phase 3: Plugin Expansion

Load additional capabilities through the plugin manager and event bus.
